# Lumen

A small static workspace with browser-side unlocking.

Only the access screen and authenticated encrypted objects are stored here. Access credentials are not part of this repository. The protected interface, documents and resources are loaded after unlocking.

The application runs without third-party analytics, external fonts or a server-side password submission. Locking closes the current view and releases temporary media URLs. Static client-side encryption is limited by the strength of the chosen passphrase and the integrity of the hosting environment.
